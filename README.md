# Symfony API

Projet Symfony genere avec `symfony/skeleton` en version 8.1.

## Demarrage

```bash
make build
make up
```

L'application est disponible sur `http://localhost:8080`.

## Commandes utiles

```bash
make console cmd="debug:router"
make composer cmd="require symfony/orm-pack"
make cache-clear
make down
```
